Téléchargez TFP Models.

Choisissez votre téléphone, installez TFP Models et trouvez une équipe pour votre prochaine séance. Sur iPhone, ouvrez l’App Store ; sur Android, suivez le guide d’installation en accès anticipé.

Pour iPhone

Ouvrez TFP Models dans l’App Store sur votre iPhone et installez l’application. Vous y trouverez aussi la version actuelle et les exigences de compatibilité.

Télécharger sur l’App Store

Voir la page App Store

Si l’App Store ne s’ouvre pas, ouvrez cette page dans Safari depuis le menu du navigateur. Vous pouvez aussi rechercher TFP Models dans l’App Store.

Pour Android

L’application Android est actuellement disponible en accès anticipé. Suivez les trois étapes ci-dessous pour l’installer depuis Google Play.

Installer sur Android

Après l’installation
